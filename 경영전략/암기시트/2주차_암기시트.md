>
> 교수 공부 가이드: "사실 텍스트의 내용을 굉장히 충실하게 따를 거고요" → 교재 정의·N가지를 용어 그대로 / 이번 주 교수 강조 1순위 = **창발적 전략**("오늘 가장 핵심", 세렌디피티 "제일 중요") + **산업의 정의**("경영전략에서 가장 핵심") + **포터 5세력**("경영전략 들었다 하면 포터 얘기해 봐") / 수업 밖이지만 보라 = **T-Mobile 영상**(3쪽, "꼭 처음부터 끝까지")

## 1. 전략·전략적 리더십·탁월한 성과·경쟁우위 (1~6쪽) ★★★

**전략과 전략적 리더십 (4쪽)** ★★★
- **전략(strategy)** = 경영자가 기업의 성과를 높이기 위해 채택하는 **일련의 행동(actions)** / 성과의 최고 목표 = 경쟁기업 대비 **탁월한 성과** 달성 → [단] 정의 빈칸
- **전략적 리더십** = 경쟁우위 창출을 위해 **전략결정 과정**을 가장 효과적으로 **관리**하는 것 / **전략결정 과정** = 전략을 **선정**하고 **실행**하는 과정 → [단]
- **전략수립(formulation)** = 외부·내부환경 분석 후 전략을 '**선정**'하는 업무 / **전략실행(implementation)** = 선정된 전략을 '**행동**'으로 옮기는 업무(제품 설계·공급, 생산 효율성 향상, 조직구조·통제시스템·문화 설계를 포함) → [선] 수립 = 선정 / 실행 = 행동 바꿔치기, 조직구조·문화 설계는 '실행'
- 【PPT 밖】 **T-Mobile**(3쪽, 교수 "꼭 다시 보라") = 전략결정 과정 사례: 만년 4위 → 존 레저 '**언캐리어**' → 1위 / 교수 포인트 ① **외부환경** 매우 나쁨(과점·소비자 불만·기술 열세) ② **내부(inward)** 점검(젊은 조직·변화 열망 vs 기술 한계) ③ 내·외부를 인지한 **전략적 선택**(+ 운) → [약] 전략결정 과정으로 설명

**주주가치와 성과 2지표 (5쪽)** ★★★
- **주주가치** = 주식 보유로 주주가 얻는 대가 = **주가 상승 이익 + 배당금** / 주주 = **위험자본(risk capital)**의 제공자 → **주주가치 극대화** = 기업의 **궁극적 목표** → [단]·[선]
- 성과의 **두 가지** 측정 지표: **수익성** = 투하자본순이익률(**ROIC**) = **순이익 ÷ 투하자본** / **이익증가율** = 특정 기간의 **순이익 증가 속도** → 전략을 통해 **두 지표를 함께** 높여야(그림 1.1: 전략의 효과 → 수익성·이익증가율 → 주주가치) → [단] 2지표·공식 / [약] 그림 1.1 구조
- 【PPT 밖】 필기 '+ 안정성' = 교수 개인 의견("텍스트에는 없기 때문에") → 시험 답은 **2지표**만 ★ / 교수 사례 APR(이익률 20%대 vs 화장품 평균 5~6%, 직원 이탈률)

**경쟁우위와 비즈니스모델 (6쪽)** ★★★
- **경쟁우위** = 산업 내 **평균 수익성보다 높은** 수익성을 달성하는 상태 / **지속적 경쟁우위** = **수년에 걸쳐** 평균 이상의 수익성 유지 → [단]·[선] 둘 구분
- **비즈니스모델** = 전략들이 어떻게 결합해 수익성과 이익증가율을 달성하는지에 관한 **경영자의 구상** / 7요소 = **고객 선정 · 제품 정의·차별화 · 고객 확보·유지 · 제품·서비스 생산 · 가격 결정 · 원가 관리 · 유통 방식** 등을 포괄하는 하나의 **통합적 설계** (두문자: 고·제·확·생·가·원·유) → [단] 7가지 ← 교수 "꼭 기억"
- 【PPT 밖】 교수 보충: BM = 전략과 **자본 투자**의 **조화로운 결합**, **한 문장**으로 답할 수 있어야("비즈니스 모델이 뭐야?" = 창업 조언 1순위) / 교수 버전 7요소엔 '**고객 가치 제공**'·'**장기 성장 목표**' 포함 → 약술이면 덧붙이기 / 코스트코 창고형 BM → 트레이더스 → [약]
- 비영리기관의 성과 = 이윤 대신 **사명 달성의 효과성·효율성** → [선] / ★ 읽고 넘기기: 성과의 산업별 차이(산업 특성 = 경쟁 강도·수요·진입장벽 → 상대평가는 **동종 산업 내**, 교수 설명 생략)

## 2. 전략적 경영자·계획수립 과정·미션·SWOT (7~10쪽) ★★★

- ★ 읽고 넘기기 (7쪽, 교수 "크게 중요하지 않아"): **총괄경영자**(전체 성과·자원 배분·전략적 의사결정) vs **기능경영자**(특정 기능 운영) / 3수준 = **기업**(CEO·이사회 — 사업 포트폴리오·전사 방향) · **사업**(사업부 총괄경영자 — 개별 시장 경쟁 전략) · **기능**(기능별 전략) → 정렬(얼라인먼트 "너무 당연") / 사례: 삼성전자 DS·DX, 현대백화점 본사–지점–팀 → [선] 3수준 ↔ 담당자

**공식적 계획수립의 5단계 (8쪽)** ★★★
- ① 기업의 **미션과 주요 목표** 선정 ② **외부환경 분석**(사업기회와 위협) ③ **내부환경 분석**(강점과 약점) ④ **SWOT**에 기초한 전략 선택(미션·목표와 일관되고, 강점과 기회를 활용하며 약점과 위협을 교정) ⑤ **전략실행**(조직구조·문화·통제시스템의 설계) (두문자: 미·외·내·S·실) → [단] 순서 / [선] "SWOT은 내부환경분석 단계"(X)
- 과정의 성격: 기능·사업·글로벌·기업수준 전략이 순차적으로 도출 / **피드백 루프** = 1회로 끝나지 않는 **연속 과정**, 실행 결과가 다음 계획수립의 투입으로 환류 / **매년** 갱신, **1~5년** 대상 → [선] "1회성"(X)

**미션·비전·가치·주요 목표 (9쪽)** ★★★ ← 교수 "조직문화의 근간, 너무 중요"
- **미션** = 기업이 '**무엇을 하는지**' — **누구를**(고객 집단)·**무엇을**(고객 요구)·**어떻게**(독자적 역량) 만족시키는가(그림 1.4 비즈니스 정의) / **제품 지향이 아닌 고객 지향**의 정의가 환경 변화에 유연 → [단] 3요소 / [선] "제품 지향이 유연"(X)
- **비전** = 미래의 **소망하는 상태**, 방향과 동기를 부여하는 '**호기성 있는**' 목표 / **가치** = 구성원의 **행동 방식과 조직문화의 근간**(종업원 존중, 자율과 책임, 공정한 처우) → [단]·[선] 셋 구분
- **주요 목표의 특성 5**: ① **정확·측정 가능** ② **핵심 사안 지향** ③ **도전적이되 현실적** ④ **달성 기간 명시** ⑤ **장·단기 균형**(단기 수익성 편향 경계) → [단] (교수 설명 없음, 교재 범위)
- 【PPT 밖】 교수 "비전과 미션과 가치는 **조직문화의 근간**이고요. 너무 중요합니다" — 훼손된 기업과의 퍼포먼스 차이 / 사례: 구글(미션), 토스(비전·가치 공유, 역체감), 일하기 좋은 100대 기업 수익률 > S&P → [약]
- 【PPT 밖】 **나쁜 기업 3특징**(교재 낭독): ① **오만한 태도**(특히 외부 아이디어에) ② **주요 이해관계자에 대한 존중 부족** ③ **변화 노력에 대한 저항** + 리더십 보인 중간·하위 경영자를 벌한 역사 (두문자: 오·존·저) → [단]

**환경분석·SWOT·피드백 루프 (10쪽)** ★★★
- 외부환경 분석 = **기회와 위협**(산업환경: 경쟁구조·경쟁자의 위치·진화 단계 / 국가환경과 거시환경) / 내부환경 분석 = **강점과 약점**(자원·역량 → 경쟁우위의 원천) → [선]
- **SWOT** = 강점(S)·약점(W)·기회(O)·위협(T) 비교 → 전략 대안 도출·평가 / 층위 **기능수준 → 사업수준 → 글로벌 → 기업수준** / 목적은 **목록 작성이 아니라** '**전략의 선택**' → [선] 목적·순서
- 전략실행 = **조직구조·문화·통제시스템·거버넌스**의 설계 / **피드백 루프** = 실행 결과의 **모니터링 → 목표·전략의 수정**으로 환류하는 **순환 구조** → [약]
- 【PPT 밖】 **피드백 루프 = 클로즈드 루프**(분석 → 실행 → 결과를 피드백받아 다시 분석으로) vs **오픈 루프**(분석·실행하고 끝) ★★★ → [약] 비교 / 교수 "외부 환경이 굉장히 중요" = 페라리도 시골길에선 모닝(길 = 환경이 성과 좌우) ★★ / 수업 순서 = 외부 → 미시(소비자, 교수 추가분) → 내부

## 3. 창발적 전략·계획수립의 실행 (11~13쪽) ★★★ ← 교수 "오늘 가장 핵심"

**형식적 계획수립 모형에 대한 세 가지 비판 (11쪽)** ★★★
- ① **예측하기 힘든 세계**의 전략결정 — 미래 예측은 **본질적으로 한계**, **몰트케** "어떤 계획도 적과의 첫 접촉에서 살아남지 못한다", COVID-19·금융위기 등 **예상 밖 충격** ② **자율적 행동** — **하위수준 경영자**에 의한 전략결정 ③ **뜻밖의 발견** — **우연한 발견·실험**이 새로운 전략을 촉발 (두문자: 예·자·뜻) → [단] 3가지 / [선] 없는 항목 끼워 넣기
- 【PPT 밖】 교수 "세 번째가 제일 중요하죠. **세렌디피티**(serendipity)" / 사례 짝: 코로나·환율 → ① / **올리브영 MD** 자율성(탑다운 아님) → ② / **3M**·**더현대 서울**(몰용 부지·코로나·국내 소싱·팝업이 우연히 겹침) → ③ → [선] 매칭 / [약]

**민츠버그의 전략 모형 (12쪽)** ★★★
- **실현된 전략 = 계획된(의도된) 전략 중 실행된 부분 + 창발적 전략** / 의도된 전략의 상당수는 **예상 밖의 변화**로 **미실현** → [단] 식 / [선] "의도된 전략 전부 + 창발"(X)
- **창발적 전략(emergent strategy)** = **계획 없이** 조직 내부에서 **자생적으로 출현**하는 전략 → [단]
- 시사점: 성공적 전략 = **합리적 계획** + **뜻밖의 발견·자율적 행동**의 결합 / **최고경영진의 역할** = 창발적 전략의 가치를 **판별**하고 계획에 **통합** → [단]
- 그림 1.5 창발의 원천 3 = 최고수준 경영자의 계획되지 않은 전략변화 · 하위수준 경영자의 자율적 활동 · 뜻밖의 발견 / w1 덱: 의도된 → **숙고된 전략**(계획대로 실현) / **창발적 전략**(계획 없이 부상) → 실현된 전략, "창발을 죽이지 않고 선별" → [선]
- 【PPT 밖】 핵심 = 계획된 전략과 창발적 전략을 **머지(merge)** / **더현대 서울** = 우연(뜻밖의 발견) + 코로나 이후 **외국인 집객**(캐리어 보관함)으로 의도된 전략 재설계 ★★★ → [약]

**시나리오 계획수립·분산된 계획수립 (13쪽)** ★★
- 계획수립 무용론? → 연구상 '**평균적으로**' 공식적 계획수립이 성과에 **긍정적**, 관건은 '**어떻게 실행하는가**' → [선] "성과와 무관"(X)
- **시나리오 계획수립** = 미래에 가능한 **복수의 상황**을 상정하고 각 **시나리오별 대응 계획**을 준비 / **단일 예측에 투자**하되 **대안 시나리오의 지표를 관찰**하다 상황 변화 시 **전략 교체** ★★★ → [단] / 【PPT 밖】 사례 = **삼성전자 평택**(수급 시나리오별 설비·공간 설계) = 계획과 창발의 머지 방법 → [선]
- ★ 읽고 넘기기 (교수 "너무 당연"): **분산된 계획수립** = '**상아탑**' 계획(본사 기획실) 실패 → **모든 수준의 경영자** 포함, 현장 지식과 결합 → [선·낮음]

## 4. 산업의 정의 (14~17쪽) ★★★ ← 교수 "경영전략에서 가장 핵심"
