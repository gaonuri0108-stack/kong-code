## 들어가기: 내부환경분석이란 (1~5쪽) ★★★

- **내부환경분석(internal analysis)** = 기업 내부의 **강점과 약점**을 파악해 **지속적 경쟁우위**를 위한 **전략 선택의 근거**를 만드는 작업 → [단] 정의 빈칸
- '내부역량'이 아니라 '내부환경'인 이유 = 역량 하나가 아니라 **자원·역량·조직·성과**가 맞물린 기업 안의 **시스템 전체**를 보기 때문 → [선] / 【PPT 밖】 ★★ 교수 "한 가지 강조": 기업 내부 = **복잡계**(탈레브 『안티프래질』 — 단순계 = 인풋→아웃풋 명확한 기계 / 복잡계 = 한 요소 변화가 전체에 파급, 생태계) → 톱니바퀴처럼 맞물린 전체 → '역량'이 아니라 '환경' → [단] '환경'인 이유
- 이 장의 질문 4 ↔ 도구 → [선] 짝: 경쟁우위는 어디에서 오는가 — **원천(자원)** / 어떤 자원이 '**오래가는**' 우위를 만드는가 — **VRIO** / 강점은 어떻게 이익으로 바뀌는가 — **V·P·C** / 강점·약점은 숫자로 보이는가 — **ROIC = 매출이익률×자본회전율**
- 【PPT 밖】 SWOT에서 내부분석 = **강점·약점(S·W)** 진단 영역(교수 처음 "O·T"는 말실수 → S·W로 정정) / '오래간다' = 우위의 **지속성**(교수 "좀 중요") / 외부분석(산업이 얼마나 매력적인가) → 내부분석(기업이 **무엇을 잘하는가**), 만나는 지점 = **SWOT, 그리고 전략 선택** → [단]
- ★ 읽고 넘기기: 강의 흐름 6절(원천 → VRIO → 가치창출과 수익성 → 가치사슬 → 구성요소 → 수익성 분석), 학습목표 6, 젠몬 영상 썸네일(5)

## 0. 도입사례: 젠틀몬스터의 경쟁우위 (6~11쪽) ★★

- 핵심 한 줄 ★★★: 유통을 없애 **비용(C)을 낮추는 데서 출발** → 지속 성장의 원천은 디자인·공간·콘텐츠로 **가치(V)를 올린 데** 있음 / PHASE 1 · 2011~ 출발 **C↓**(유통 단계 제거로 확보한 마진 → 디자인·공간에 재투자) → PHASE 2 · 2014~ 지속 **V↑**(기능이 같은 안경에 프리미엄 가격, 2024년 영업이익률 **약 30%**) → [선] 출발(C↓) vs 지속(V↑), PHASE 짝
- 기존 아이웨어 vs 젠몬 6구분(8) → [선] 짝: 유통구조 = 브랜드 → 도매 → 안경원 납품 vs **D2C**(자체 매장 직접 판매, 중간유통 제거) / 브랜드구조 = 브랜드·제조 분리(룩소티카 라이선스) vs 디자인·기획·유통을 **한 회사가 직접** / 안경의 의미 = 시력보정 도구 vs 얼굴 위의 '**오브제**' / 디자인 = 클래식 vs 실험적 형태·빠른 컬렉션 교체 / 매장 = 진열·판매 vs **전시·콘텐츠 공간**(갤러리형 플래그십) / 마케팅 = 광고·셀럽 협찬 vs 아티스트·브랜드 협업 + **공간 자체가 미디어**
- 기능별 활동 5가 **한 방향으로 정렬**(9): **유통 · 디자인 · 공간 · 콘텐츠·협업 · 포트폴리오**(탬버린즈·누데이크) → [단] / 【PPT 밖】 ★ 영업이익률 30% = 에르메스 40%·LVMH 20% 중반에 가까운 명품 수준 / 젠몬 우위 = **V는 크게 높이고 C는 크게 줄임**
- **재량근로제 = 근로기준법 제58조 제3항**(10): 디자인·연구개발처럼 **재량이 큰 업무**는 실제 근로시간과 관계없이 **노사 서면합의 시간을 근로시간으로 간주** → VRIO의 '**O(조직)**' 이슈 / 교재 **이케아** = 조립·운반 활동을 **고객에게** 넘겨 C↓ vs 젠몬 = 디자인·공간 비용 일부를 **디자이너의 시간**으로 흡수해 V↑ → [선] 조문 번호, 이케아 vs 젠몬 / 【PPT 밖】 ★ 교수: 핵심 자원인 디자이너 시간을 비용 낮추는 쪽으로 쓴 것이 지속 가능했는지 "퀘스천" = **조직(O)의 리스크**
- 【PPT 밖】 ★★★ Discussion(11) "한국·아시아에서 통한 우위가 **유럽·미국에서는 왜 아직 이익으로 이어지지 않는가**" 교수 답 3 → [약]: ① 고객·경쟁자 — 한·중·일은 안경 = **패션 아이템**으로 보는 전환이 빨랐음 / 유럽·미국은 **실용품** 인식 + **레이밴·오클리** 같은 기존 브랜드 레퍼런스가 강함 ② '매장 = 미디어'는 **유동 인구·방문 밀도** 전제 → 도산·상해·도쿄는 되지만 구미는 어려움 ③ 조직 — 재량근로제 논란 자체가 **조직력의 구조적 약점** 시사(정확한 판단은 내부 인터뷰 필요) / VRIO로 읽으면 같은 자원도 시장(고객 인식·방문밀도)에 따라 **V가 달라짐**
- ★ 읽고 넘기기(교수 "창업 스토리·실적은 영상에 다 나와 설명 안 함"): 영어강사 **김한국** 대표 · **2011년** 자본금 5천만 원 · 2013 논현동 첫 매장 · **2014년** 천송이 선글라스 / 실적 2024 매출 7,891억·영업이익 2,339억 → 2025 7,723억(−2.1%)·1,770억(−24.3%) = **5년 만의 역성장**, 해외 **16개 법인 중 9개** 순손실·중국 3개 법인 완전자본잠식 / 노동부 감독 경과(2026.1 착수 → 7.1 결과: 재량근로제 도입 자체는 **적법**)

## 1. 경쟁우위의 원천 (12~15쪽) ★★★

- **경쟁우위(competitive advantage)** = 기업의 수익성 > 산업 내 모든 기업의 **평균 수익성** / 수년간 평균 이상의 수익성 유지 = **지속적 경쟁우위** → [단] 정의 / [선] 둘 구분
- 【PPT 밖】 ★★ 교수: 경쟁우위의 수익성은 **단순 매출도, 점유율도, 브랜드 인지도도 아님** → [선] 오답 보기 함정 / 젠몬 = 10년간 평균 이상 수익성 → 지속적 우위 맞음(2025년 감소로 시험대)
- 내부분석 3 STEP → [단] 순서(= 이 장의 진행 순서): ① **자원의 역할**(가치 있고 모방하기 어려운 자원이 우위를 만드는 방식) ② **우위의 경로**(자원 → 효율성·품질·혁신·고객대응성) ③ **수익성 연결**(강점이 수익성을 높이는 방식, 약점이 낮추는 방식)
- **독보적 역량(distinctive competence)** = 경쟁사와 제품을 **차별화**하거나 **상당히 낮은 비용**으로 생산할 수 있게 하는 **기업 고유의 강점** / 경쟁우위는 독보적 역량에 기반한다는 것이 **오랜 통설** → [단] 정의 빈칸
- 사례 짝 → [선]: **애플 — 디자인**(산업디자인 그룹이 개발 프로세스를 시작·조정, 하드웨어·소프트웨어·제조가 디자인 사양을 중심으로 협력) = **차별화(V↑)형** / **토요타 — 제조공정**(**JIT** 재고 시스템, 자체관리팀, 복잡한 장비의 설정시간 단축 = '**토요타 린 생산 시스템**') = **저원가(C↓)형**
- 【PPT 밖】 ★ 교수: 차별화/저원가 2분법은 "조금 예전 모델" — **다이소** = 비용을 독보적으로 줄이면서 품질도 뛰어나고(가격 먼저 정하고 제품 개발) 차별화 기업과 협업 = '육각형' / 단 시험 답은 **2분법**
- **자원(resources)** = 입력을 시장에서 판매 가능한 출력으로 바꾸는 데 쓰이는 요소 — 독보적 역량은 **한 개 이상의 자원**에 뿌리를 둠 → [단]
- 자원 분류(15, 기업은 자원의 번들) → [단] 4+2 / [선] 기본 vs 고급(건물·장비 = 기본, 특허 = 고급):
  - **기본 생산요소** 4 = **노동 · 토지 · 경영(관리) · 플랜트·장비**(두문자 노토경플)
  - **고급 생산요소** 2 = **프로세스 지식(능력)**(하나 이상의 기능에서 일을 수행하는 방법) · **지적재산**(저작권·상표·특허)
  - 가운데 띠 **조직 아키텍처(설계)** = 자원을 묶어 입력을 산출로 바꾸는 방식을 결정 (★ 교수 "12장에서 더 볼 것, 이 개념이 있다 정도로만" — 정의 한 줄만)
- 【PPT 밖】 ★★★ 프로세스 지식의 특성 2: ① **사회적으로 복잡**(여러 개인 간 상호작용) ② **암묵적**(문서화·규정화 불가, 경험·직관으로 이해 — 교수 "이게 더 중요한 게 암묵지") / 조직 내 규칙·루틴·절차에 내재 → [단] 2가지
- 【PPT 밖】 ★★★ 프로세스 지식 = **가져오기 가장 어려움**(교수 "굉장히 어렵습니다") → [약]: 기본 생산요소 = 자본만 있으면 삼 / 지적재산 = 특정 인물 영입으로 가져올 수 있음 / 프로세스 지식 = 사회적으로 복잡해 시간 걸리고 모방 어려움 → VRIO **모방 불가능성의 대표 사례**
- 【PPT 밖】 ★★ 교수 구분: 노하우가 사람·루틴에 **암묵적**으로 있으면 프로세스 지식, **문서화**되면 지적재산(노포 비공개 레시피, **코카콜라** 제조법 비밀, 애플 디자인·특허·로고) / 조직 아키텍처 = 조직 구조·인센티브 시스템·문화·HR 전략의 조합 / 고급 생산요소 = 핵심 경쟁우위에 기여하는 **핵심 자원**

## 2. 자원의 품질: VRIO 프레임워크 (16~19쪽) ★★★ ← 선택형·약술 1순위

- 학자: **제이 바니(Jay Barney)**와 **빌 헤스터리(Bill Hesterly)** — **자원 품질 평가** 프레임워크(Strategic Management and Competitive Advantage, 2005) → [단] 학자명
- 네 가지 질문(17) → [단] 4질문 쓰기 / [선] 글자 ↔ 질문 ↔ 판단 짝

| | 질문 | 판단 |
| --- | --- | --- |
| **V** Value · 가치 | 기회를 활용하고 위협에 대처하는 데 도움이 되는가? | **수요 창출 or 비용 절감**에 기여하면 가치 있음 |
| **R** Rarity · 희귀성 | 경쟁사도 쉽게 획득할 수 있는가? | 누구나 가진 자원은 우위의 원천이 되지 못함 |
| **I** Inimitability · 모방불가능성 | 복사하기 쉬운가, 어려운가? | 쉽다면 우위는 빠르게 약화 |
| **O** Organization · 조직 | 가치를 확보하도록 조직화·관리되는가? | 올바른 조직·관리시스템이 없으면 자원이 있어도 불리 |

- 판정표(18) → [선] 표 빈칸·행 매칭 최유력(외우기: **V 없으면 열위, R 없으면 동등, I 없으면 일시, 다 있으면 지속**)

| V 가치 있는가? | R 희귀한가? | I 모방이 어려운가? | O 조직화되어 있는가? | 경쟁적 함축 | 성과 수준 |
| --- | --- | --- | --- | --- | --- |
| No | — | — | — | **경쟁 열위** | **평균 이하** |
| Yes | No | — | — | **경쟁 동등** | **평균** |
| Yes | Yes | No | — | **일시적 경쟁우위** | **평균 이상 → 소멸** |
