# 경영전략 3주차 암기 시트 — 미시환경분석(w3 1~65쪽)

> ★★★ 무조건 암기(교수 강조·프레임·정의) / ★★ 암기 / ★ 읽고 넘기기(교수 "넘어감"·"이해만") · [단] 단답 [선] 선택형 [약] 약술 · 【PPT 밖】 = 슬라이드엔 없는데 교수가 강조 → 암기 · 【정정】 = PPT 오타·교수 정정 · (숫자) = 슬라이드 쪽
>
> 교수 공부 가이드: 이번 주 시험 직접 언급 없음. 미시환경은 **교재에 없는 교수 본인 연구 영역 → PPT·강의 자체가 출제 근거**. 실제 설명 1~49쪽(핵심), 50~53쪽 "마케팅 영역이라 볼 필요 없다", 54~65쪽 미진행 / 이번 주 교수 강조 1순위 = **욕구 vs 욕망 구분·욕망을 설계**("이게 저는 핵심") + **소비자 관찰**("오늘의 핵심 포인트 … 시작은 결국 소비자들의 관찰") + **마켓 5.0 = 단절·양극화, 확장성**("항상 생각")

---

## 1. 미시환경의 의미와 변화 (1~12쪽) ★★★

**1.1 미시환경의 의미 (5쪽)** ★★★
- **전통적 의미의 미시환경** = 제조·공급업체·유통·타겟고객 등 **어느 정도 제어**할 수 있는 환경 / 소비자 시장환경 관점에서는 '**마케팅 환경**'과 관련한 요소들에 해당 → [단] 정의 빈칸 / [선] 거시환경(통제 불가)과 대비
- 【PPT 밖】 미시환경 분석 = "진짜로 소비자들을 **관찰**", '왜·무엇을 좋아하는지'를 넘어 **욕망**까지 분석 / 경영진 핵심 아젠다 = 지금 트렌드가 **패드(fad)**인지 뛰어들어도 되는 트렌드인지 판단 / 명칭 유래 = 사회학의 미시적 관점(개인 간 상호작용) → [약] 미시환경 분석의 특징
- ★ 읽고 넘기기: 4쪽 영상(AGI vs 내로우 AI — "AI 흐름 감각", 출제 가능성 낮음) / 2쪽 목차 2절 9개 순서 = 욕구·정서·심리·수요·세분화와 페르소나·관계·유통·촉진·조사

**1.2 마켓 1.0 → 5.0 (5~6쪽)** ★★★
- 도식: 1.0 **제품 중심**(많은 기능과 높은 품질의 제품 공급 중심) → 2.0 **고객 중심**(소비자의 needs 중심) → 3.0 **인간 중심**(고객이 소비를 통해 충족하려는 가치 중심) → 4.0 **전통적 방식에서 디지털 방식으로 전환**('**옴니 채널**' 전략 활용) → 5.0 **휴머니티를 향한 기술**(인간과 차세대 기술의 융합으로 지속 가능한 사회) → [선] 단계↔키워드 매칭
- 1.0~3.0 = '고객 만족'의 필요 조건을 모두 갖춘 **전통적 마케팅**의 최종적 단계 / 4.0~5.0 = 기술의 발달로 시장 환경의 **디지털 전환** → [선]
- 코틀러 비교표(6쪽) — 교수 "키 마케팅 컨셉과 마케팅 가이드라인 정도만" → 두 행만 암기, 나머지 행(Concentration·Aim·Forces·Value proposition·Interactions) ★ 읽고 넘기기

| | 1.0 | 2.0 | 3.0 | 4.0 |
| --- | --- | --- | --- | --- |
| **Key marketing concepts** | **Product development**(제품 개발) | **Diversification and distinction on the market**(시장에서의 다각화·차별화) | **Providing higher values**(더 높은 가치 제공) | **Anthropomorphization of brands**(브랜드의 의인화) |
| **Marketing guidelines** | **The specificity of the product**(제품의 특수성) | **Positioning the company and product**(기업·제품 포지셔닝) | **Mission, vision and company values**(미션·비전·기업 가치) | **Promoting content and creating brands**(콘텐츠 홍보·브랜드 창조) |

- → [선] 단계↔키 컨셉 매칭(3.0 = 더 높은 가치 제공, 4.0 = 브랜드의 의인화) / Source: Kotler et al. 2010, 2017
- 【PPT 밖】 ★★★ **나음**(1.0) → **다름**(2.0) → **나다움**(3.0) — 교수 "제일 좋아하는 표현", 3.0 = 자기 가치를 표현하는 수단 / 3.0 이후 한국 소비자 가치 전환 사례 = **소확행** → [단] 마켓 단계에 연결 / (필기) 공급자 입장 = 나음, 소비자 입장·소비자 만족 = 다름·나다움
- 【PPT 밖】 ★★ 단계별 대표 도구: 1.0 = **4P** / 2.0 = **STP** / 3.0 = **3i** / 4.0 = **5A**("4.0은 조금 그래도 봐야") → [선] 단계↔도구 매칭
- ★ 읽고 넘기기(7~9쪽, 교수 "너무너무 잘 아는 개념 … 뭐라 했었지 정도로만"): 4P = PRODUCT·PRICE·PLACE·PROMOTION → TARGET MARKET / STP = 시장세분화(고객의 여러 특성을 고려해서 고객이 모여있는 시장을 나눈다)·표적 시장세분화(시장 상황을 고려해서 어떤 고객을 대상으로 사업할지 정한다)·제품 포지셔닝(다른 기업에 비해 고객에게 어떻게 차별성을 가질지 정한다) / 3i(팀버랜드 역삼각형: POSITIONING·DIFFERENTIATION·BRAND) = brand **integrity**(포지셔닝–차별화)·brand **identity**(포지셔닝–브랜드)·brand **image**(차별화–브랜드)

**마켓 4.0 — 5A 고객 경로 (10쪽)** ★★★ (교수 "4.0은 조금 그래도 봐야")
- 연결 전 **4A**: A1 **인지 AWARE** → A2 **태도 ATTITUDE** → A3 **행동 ACTION** → A5 **반복행동 ACT AGAIN**
- 연결 후 **5A**: A1 **인지 AWARE** → A2 **호감 APPEAL** → A3 **질문 ASK** → A4 **행동 ACTION** → A5 **옹호 ADVOCATE** → [단] 5A 순서 / [선] 4A→5A 바뀐 단계(태도→호감+질문, 반복행동→옹호)
- 고객 상황 짝: 인지 = **안다** · 호감 = **좋아한다** · 질문 = **확신한다** · 행동 = **구매한다** · 옹호 = **추천한다** → [선] 단계↔고객 상황
- 고객 행동 키워드: 인지 = 많은 브랜드에 **수동적으로 노출** / 호감 = **몇몇 브랜드에만 끌린다** / 질문 = **직접 적극적인 조사**에 착수(친구 조언·온라인 사용 후기·콜센터·가격비교·매장에서 시제품) / 행동 = 특정 브랜드를 **구매**하기로 결정하고 구매, 사용, 사후 서비스 과정을 통해 브랜드와 깊이 있게 상호작용 / 옹호 = 충성심은 **유지, 재구매, 브랜드를 옹호**하는 행동으로 나타남(지속사용·재구매·추천)
- 변화 3: ① 브랜드 태도의 결정 주체는 **고객**, 일차적 호감은 **커뮤니티**에 영향 ② 연결된 시대의 **충성심**은 궁극적으로 브랜드에 대한 **옹호 의사**로 정의 ③ 브랜드와 질문/옹호 관계 구축 — 대화 도중 드러나는 편향에 따라 브랜드에 대한 호감을 약화 또는 강화시킨다 → [선] "충성심 = ○○ 의사"
- 【PPT 밖】 ★★★ 4.0의 핵심 = **옹호(advocate)** "가장 핵심은 애드보케이션" / 호감 = 이성적 판단이 아닌 미시적 감정, 질문 = 리뷰 확인 등 내 질문에 대한 답을 탐색 / 예: 교수 아이폰 18(인지 → 호감 → 유튜브 리뷰 → 구매 → 자랑 = 옹호) → [약] 5A 사례 적용
- 【PPT 밖】 ★★ 최근 3년 기업 연구 의뢰 최다 주제 = **팬덤**(SK하이닉스: B2B를 넘어 사랑받는 브랜드) ← 신규 고객 모객 비용↑·인구 정체 → **리텐션**(기존 고객을 팬덤으로) → [약] 팬덤·리텐션 중시 배경

**마켓 5.0 — 4가지 양극화, 단절 (11쪽)** ★★★
- **직업의 양극화**: 고부가가치의 고임금 일자리와 저부가가치의 저임금 일자리가 늘어나면서 **중간**에 있던 모든 **일자리가 줄어든다**
- **이데올로기의 양극화**: **보호무역주의 대 자유무역주의** 같은 양극화된 세계관과 이데올로기가 사람들 사이의 대립을 격화시킨다
- **라이프스타일의 양극화**: **미니멀리스트**와 **소비지상주의자**의 라이프스타일이 모두 유행하면서 사람들의 제품과 서비스 구매 방식에 영향을 준다
- **시장의 양극화**: **프리미엄 명품** 시장과 **가성비** 좋은 제품 시장은 성장하나 **중간 시장은 축소** (두문자: 직·이·라·시) → [단] 4가지 / [선] 내용↔이름(중간 일자리 = 직업, 중간 시장 = 시장)
- 【PPT 밖】 ★★★ 5.0 등장 계기 = **코로나**(인류가 휴머니티를 회복해야 한다는 인식) + 트럼프 정부 이후 이데올로기 양극화 / "5.0이라고 했지만 핵심은 결국 **시장의 양극화**"(+커스터마이제이션)
- 【PPT 밖】 ★★★ 마켓 5.0 한마디 = '**단절**'(단절·양극화·파편화) → 세그멘테이션 **그룹핑 불가능** → 단절을 **휴머니티**로 통합하자는 게 5.0 / 미시환경 분석의 주 아젠다 = 그룹핑 불가 상황에서의 전략적 접근 → [약] 5.0에서 STP가 어려워지는 이유
- 【PPT 밖】 ★★ 양극화 사례 짝: 시장 = **올리브영** 세일 당월·익월 매출 변동폭 확대(22년 +10%/−8% → 25년 +30%/−20%) / 라이프스타일 = '**○○코어**' 2025년 한 해 18종, 추구미 다변화 / 직업 = **반도체 사이클**(동일 산업·직종·직장 안에서도 양극화) / 이데올로기 = 한국 소비자 사례 없음 → [선] 사례↔양극화 유형

**마켓 5.0 — 직업의 확장성 (12쪽)** ★★★ (교수 "항상 이거 생각했으면 좋겠습니다. 스케일러빌리티")
- **직업의 확장성(Scalability)** = 어떤 사람의 **동일한 노동 단위**를 **여러 차례 반복해서 판매**할 수 있는 직업 / 산출물을 **한계비용 0**에 가깝게 복제, 배포할 수 있는 직업일수록 **미세한 품질, 지위적 우위**가 시장을 이끈다 → [단] 정의 빈칸
- 도식 Scalable Business Models: **GROWING**(Revenues와 Costs가 함께 증가, Investments가 계속 들어감) vs **SCALING**(Investments는 초기 한 번, Revenues는 가파르게 증가, Costs는 완만하게 증가) → [선] Growing vs Scaling
- 【PPT 밖】 ★★★ 확장성 사례 짝: **삼양식품**(불닭 IP·플랫폼화, 매출 80% 수출, 5년 **+1,493%**) vs **농심**(**+35%**) / 동네 미용실 1·2등 매출 차이(몇 명) vs **스포티파이** 1위·100위 가수의 삶 차이 → 디지털화될수록 경쟁 변화 극대화, 4.0은 1·2·3과 판이 다름 → [선] 사례 매칭
- 【PPT 밖】 ★★ 5.0 전략: 소비자 조사 → 타겟 페르소나 → 4P·유통 식의 3.0/4.0 방식은 "잘 안 돼요" → **디테일**에 들어가야, 한순간의 **감각·직감·판단력** "전략이 진짜 달라야 돼요" → [약] 5.0 시대 전략이 달라야 하는 이유

## 2. 전통적 미시환경 분석 ① 소비자 욕구 분석 (13~22쪽) ★★★ ← 교수 "이게 저는 핵심이거든요"

**니즈·원츠·디맨즈 (14쪽)** ★★★
- **필요(needs)** = 소비자의 **생리적·사회적·개인적** 욕구 — 니즈는 **원츠로 전환**될 수 있음 / 5가지 유형: **분명한 니즈·진정한 니즈·분명하지 않은 니즈·기쁨의 니즈·숨겨진 니즈** → [단] 니즈 5유형
- **욕구(wants)** = 니즈를 충족하기 위해 "**○○하고 싶다**"고 생각하는 욕구의 **구체적 형태·대상**
- **수요(demands)** = 구매 의사가 있는 수준으로 욕구가 높아진 상태 = **구매력을 동반한 원츠** / 가지고 싶어도 **예산과 맞지 않으면 실현되지 않음** → [단] "구매력을 동반한 원츠 = ?" / [선] 3개념 구분
- 【PPT 밖】 ★★ 짝 사례: 목이 마르다(**니즈**) → 물을 마시고 싶다·**스탠리 컵**을 사고 싶다(**원츠**) → 살 돈과 의사가 있음(**디맨즈**) / 니즈의 기본 = **매슬로** 욕구 5단계 → [선] 사례로 3단계 구분

**욕구 vs 욕망 — 지라르 욕망의 삼각형 (15쪽)** ★★★
- 【정정】 PPT 표의 '**욕구(need)**'는 **원츠(wants)**의 오타 — 교수 "여기서의 욕구는 니즈가 아니라 … 원츠가 됩니다" → 욕구 = wants, 욕망 = desire → [선] "표의 욕구 = 니즈"는 X

| 구분 | 욕구(wants) 【정정: PPT는 need】 | 욕망(desire) |
| --- | --- | --- |
| 주체–대상 관계 | 주체와 대상이 **직접 연결** | **타인·사회와의 관계** 속에서 형성 |
| 작동 구조 | **선형적**·비교적 예측 가능 | **비선형적·맥락 의존적**·예측 어려움 |
| 통제 가능성 | **제도·법·교육**으로 관리 가능 | 제도적 통제 어려움 — **윤리적 규범**의 영역 |
| 문화적 성격 | **보편성** 강함 | **문화·시대**에 따라 표현 방식 변화 |
| 지속성 | 충족되면 **소멸(perishable)** | 충족되어도 **대상만 바뀌며 전이** |

**약술형 뼈대**
1. 결론: 욕망 설계가 지속 가능한 전략(교수 "사업을 설계할 때 … 욕망을 설계해야") → ① 욕구(wants) = 주체–대상 직접 연결, 선형, 제도·법·교육으로 관리, 충족되면 소멸(perishable) — 욕구는 상수이며 충족 순간부터 빠르게 매력을 잃음(풍미 강한 맛 빨리 질림) ② 욕망(desire) = 타인·사회 관계 속 형성, 비선형·맥락 의존, 윤리적 규범 영역, 충족돼도 대상만 바뀌며 전이(인정 욕망 → 자동차 → 명품 → 친환경 소비) ③ 지라르 삼각형: 욕망은 대상을 직접 향하지 않고 중재자(타인)의 욕망을 모방 → 대상은 계속 바뀌어도 욕망은 꺼지지 않음 ④ 시사점: 소비자가 꿈꾸는 아이디얼을 제시하는 것이 5.0 시대의 설계도 / 【정정】 15쪽 표의 '욕구(need)'는 원츠
2. ① 프레임: 주체(나) → 중재자(흠모하는 타인, 아이디얼) → 대상(제품) / 주체→대상은 점선, 중재자 경유가 실선 ② 대입(교수 예): 중재자 = 장원영, 대상 = 두쫀쿠(→ 차이티로 전이) — 두쫀쿠를 먹는 것은 장원영의 라이프스타일을 따라가는 것 ③ 함의: 대상은 바뀌어도 중재자를 향한 욕망은 지속 → 기업은 개별 제품(대상)이 아니라 중재자·아이디얼을 설계·점유해야 ④ 연결: 한국 = 외부지향·따라하기 성향 최고(42쪽) → 모방 욕망 자극이 유효 / 5A의 호감(커뮤니티 영향)·옹호와도 연결
3. ① 해석 틀 3: 기간1→2 비율·순위 변화 / 감성어의 질적 변화 / 연관어의 이중 의미 ② 인사이트 1(교수): AI 감성어가 '빠르다·혁신'(도구·효율) → '사랑·믿다·응원·지지'(정서적) = AI의 반려성 증가, 동시에 부정어가 '우려' → '망하다·공포·싫다'로 감정 양극화 심화 ③ 인사이트 2(교수): 반려식물 부정성(4%) < 반려동물(17%) — 동물은 '건강'이 같이 끌려옴 = 책임·기회비용 부담 → 책임은 덜하되 반려 감정은 느끼는 식물·고양이 선호(교차 검증: 반려묘 입양 증가세, "낄끼빠빠·책임이 덜하다") ④ 주의: '건강'이 누구의 건강인지 등 연관어 분류를 구분해야(학생 의견, 교수 동의)
4. ① VALS Ⅰ: 외부지향(타인의 시선·사회 규범, 소속자→경쟁자→성취자) vs 내부지향(내적 가치·취향, 자기중심자→경험주의자→사회의식자) — 교수: 변수 하나면 자아 지향 vs 타자 지향 ② 한국 = 외부지향·경제적 과시(독일은 유기농으로 지적 우월 과시, 유럽 = 내부지향) ③ 외부지향의 2메커니즘 = 따라하기 vs 구별짓기 → 한국은 세대 불문 따라하기 최고("한국만큼 … 높은 나라는 좀 없다") ④ 근거: 골프 소비 비중 최상위 30% < 차상위 40% → 럭셔리의 진짜 타겟은 초고소득자가 아니라 따라가고 싶어 하는 하위 계층의 욕망 자극 / 키링도 결국 다 같은 키링(찐 내부지향자 드묾)
