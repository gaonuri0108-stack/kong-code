# 경영전략 5주차 암기 시트 — 사업수준전략(Ch4) + 기능수준전략(Ch5)

> ★★★ 무조건 암기(교수 강조·프레임) / ★★ 암기 / ★ 읽고 넘기기(교수 "넘어가도 된다") · [단] 단답 [선] 선택형 [약] 약술 · 【PPT 밖】 = 슬라이드엔 없는데 교수가 강조 → 암기 · (숫자) = 슬라이드 쪽
>
> 교수 공부 가이드: "넘겨주세요 했던 부분은 이해 수준, 핵심적인 부분은 잘 봤으면" / 이번 주 교수 강조 1순위 = **효율성곡선·가치혁신**("진짜 중요하게 강조") + **정렬(alignment)**("굉장히 중요")

---

## 1. 사업수준전략이란 (5쪽) ★★★

- **사업수준전략** = 시장에서 회사의 **주요 경쟁 테마** / 특정 산업이나 시장에서 **경쟁우위를 구축하고 유지**하기 위해 **개별 사업 단위**로 선택하는 경쟁 전략 → [단] 정의 빈칸
- 3질문: **WHO**(누구에게 → 고객 세그먼트의 선택) · **WHAT**(어떤 니즈·욕구 → 고객이 원하는 것의 정의) · **HOW**(어떻게 → **저원가 or 차별화**) → [단] 3질문 / [선] 질문↔내용 짝
- 【PPT 밖】 거시적으로 전략은 결국 "**저원가냐, 차별화냐**" (교수)

## 2. 저원가와 차별화 (7~12쪽) ★★★ ← 이번 주 출제 1순위

**저원가 (7쪽)** ★★
- 상품시장(commodity market) = 가격 외에는 모두 비슷한 시장(정유·밀·알루미늄·철강) → **가장 낮은 원가를 실현한 기업이 경쟁우위** / 비상품 산업에서도 유효: **월마트**(경쟁사가 적자 내는 가격에서도 이익), **사우스웨스트항공** → [선] 사례
- ★ 읽고 넘기기: 엑슨모빌 3.5% 수치
- 【PPT 밖】 사례 짝 ★★: **다이소**(물류센터·PB 70%↑·고정비↓·정찰제·광고 0) / **디오디너리**(용기 통일 → 규모의 경제, **D2C**) → [약] 사례 속 원가 절감 요인 → 개념

**차별화 (10쪽)** ★★★
- **차별화** = 회사를 경쟁사와 **구별**시키는 것 → [단]
- BENEFIT 1 **프리미엄 가격**(포시즌스) · BENEFIT 2 **수요 증대·점유율 확대**(아이폰) · CAUTION **비용구조 상승**(차별화 기업은 대개 저원가 기업보다 **높은 비용구조**) → [단] Benefit 2 + Caution 1 / [선] O·X

**효율성곡선 (11쪽)** ★★★
- **효율성곡선(생산가능곡선)**: 가로 저원가(오른쪽일수록 원가↓) × 세로 차별화↑ / 곡선 위 = **노드스트롬**(고차별화) ↔ **월마트**(저원가) / 곡선 **안쪽** = **갭(Gap)** = 비효율 → [선] 기업 위치, 안쪽 기업의 의미
- 【PPT 밖】 교수 핵심: 저원가·차별화는 **상충 관계가 아니다** — 곡선 위 **다양한 위치를 선택** 가능 / 볼록한 모양 = **수확체감** → [약] 상충하는가

**가치혁신 (12쪽)** ★★★
- **가치혁신(value innovation)** = 혁신을 통해 산업의 **효율성곡선을 바깥으로 이동**시켜, 이전보다 **더 낮은 원가와 더 탁월한 차별화**로 **더 큰 가치**를 제공하는 것 → [단] 정의 빈칸
- **효율성곡선은 고정돼 있지 않다** / 사례 = **델(1985 → 2005)** PC 산업 → [선] O·X, 사례
- 【PPT 밖】 교수 "효율성곡선은 **항상 확장 가능**" → [약] 답 뼈대: 이론적 상충(포터) → 곡선 위 다양한 위치 → 가치혁신으로 바깥 이동(델)

## 3. 시장세분화 (14쪽) ★★★

- **시장세분화** = 시장을 **유사한 니즈·바람·요구 특성**을 가진 **고객 집단들로 명확히 구분**하는 과정 → [단]
- 3접근: **표준화**(세분시장 고려 X, 단일 제품 대량 판매 → **규모의 경제, 저원가**) · **세분화**(다수의 세분시장에 각기 다른 제품 → 원가↑, 단 **린생산·대량맞춤생산**으로 완화) · **집중화**(한정된 소수 또는 단 하나의 세분시장 → **규모의 경제 어려움**) → [단] 3접근 / [선] 원가 최저 = 표준화, 규모의 경제 어려움 = 집중화
- 【PPT 밖】 사례 짝 ★★: 표준화 = **포드 T**·P&G / 세분화 = **로레알·BMW** / 집중화 = **라페라리**(고가)·**달러숍**(저가 — 집중화는 고가에만 해당 X) / 정밀 세분화 = 룰루레몬 / 교수 "**누구를 타겟하세요**" = 시장의 시작점

## 4. 본원적 사업수준전략 (15~16쪽) ★★★

- **본원적 사업수준전략** = 경쟁자와의 관계에서 **평균 이상의 이윤**, 특정 형태의 **경쟁적 지위와 경쟁우위**를 가져다주는 전략 → [단]
- 2×2 축: **경쟁우위의 원천**(저원가/차별화) × **시장 범위**(넓음/좁음) → [단] 두 축

| | 저원가 | 차별화 |
| --- | --- | --- |
| 넓음(시장 전체) | **전반적 저원가** — 낮은 가격으로도 지속적 이윤 | **전반적 차별화** — **세분화 전략 기업은 기본적으로 이 전략** |
| 좁음(틈새) | **집중화된 저원가** — 틈새시장에서 저원가 주자 | **집중화된 차별화** — 특정 세분시장에 기능·특성을 더한 맞춤 제품 |

- → [단] 4가지 / [선] "세분화 전략 기업 = 전반적 차별화" 함정 / 사례(교수): 전반적 저원가 = 월마트·이마트·다이소, 집중화된 저원가 = **코스트코**·달러숍, 집중화된 차별화 = 포르쉐
- **stuck in the middle(Porter)**: 차별화는 원가를 올리므로 저원가 위치 획득이 **불가능**, 저원가를 원하면 차별화 여력이 **극히 제한적** → 전략 하나를 명확히 → [단]
- 【PPT 밖】 교수 반론 ★★★ → [약] "오늘 질문하고 싶은 것": 포터는 **이론적으로는 맞지만** ① **혁신**(스케일러빌리티·플랫폼화)으로 둘 다 달성하는 기업 증가 ② **기업 인식 변화** — 저원가 기업도 차별화 포인트를 같이 가져감(코스트코) → 효율성곡선·가치혁신과 연결해서 쓸 것

## 5. 경쟁우위와 실행 (18~20쪽)

- ★ 읽고 넘기기 (18쪽, 교수 "중요하지 않다"): 5세력별 저원가 기업/차별화 기업 보호 방식 표 → 핵심 한 줄만: 저원가 = 가격으로 보호 / 차별화 = **브랜드 충성도**로 보호 / 코스트코(적은 SKU·벌크), 포르쉐(고급 이미지) = 집중화 기업의 추가 우위
- **정렬 (19쪽)** ★★★: **사업수준전략 → 기능전략 → 조직배치** = **정렬(alignment)과 적합성(fit)** / "전략이 경쟁우위로 전환되려면 **기능 수준의 조치와 조직배치가 사업수준전략을 뒷받침**해야 한다" → [단] 3층 구조·두 용어
  - 저원가 조직 = **평평한 구조**, 생산성·비용 중심 측정과 통제, **검소한 문화** / 차별화 조직 = **애플**(산업디자인 그룹이 신제품 개발 주도, 엔지니어링이 디자인에 보고) → [선]
  - ★ 읽고 넘기기: LOW COST·DIFFERENTIATION 세부 목록(교수 "읽어주시면")
- 【PPT 밖】 **버드라이트(20쪽)** = **정렬 실패** 사례 ★★★ → [약]: 마케팅 단발 실행(딜런 멀바니 캔) ↔ CEO 침묵·유통·기존 고객 비정렬 → 시총 270억 달러 증발, 1위를 모델로에 내줌 / 핵심 = **실행(execution)에서의 alignment**

## 6. 블루오션과 가치혁신 (21~23쪽) ★★★

- 학자: **김위찬·마보안** / 블루오션 = 새로운 시장 공간을 창출 → [단]
- **전략캔버스(22쪽)**: 가로 **Competing factor** × 세로 **Offering level** / 아이폰 사례 = ELIMINATE 모델 다양성 · REDUCE 물리 버튼 수·비즈니스 앱·PC급 성능 · RAISE 모바일 인터넷·스타일&재미·사용 편의성 · CREATE **앱스토어 커스터마이징** / 가격 높음 → [선] 요소→ERRC 분류
- **ERRC(23쪽)**: **ELIMINATE 제거**(당연시하는 요인 → 원가↓) · **REDUCE 감소**(산업 표준 미만 → 원가↓) · **RAISE 증가**(산업 표준 이상 → 가치↑) · **CREATE 창조**(경쟁사가 제공하지 못하는 것 → 가치↑) → [단] 4질문 / [선] E·R = 원가, R·C = 가치
- 가치혁신이 지속적 우위가 되는 이유 = 경쟁사의 **허를 찌르고 추격을 어렵게** → **조직관성과 이전 투자의 파기비용** / 델 인터넷 직판 ↔ 소매 유통에 투자한 경쟁사, 사우스웨스트 ↔ 전통 항공사 → [단] 핵심 두 단어 / [선] 사례
- ★ 읽고 넘기기: 캔버스에 정답은 없음, 트레이더 조(팀플용)

## 7. 기능수준전략 개요 (25쪽) ★★★

- **기능수준전략** = **가치창출 활동의 효율성과 효과성을 개선**하기 위해 경영자가 행하는 활동(**가치사슬 활동에 대한 전략적 투자**) → [단]
- 도식: 기능전략 <가치 있는 **자원**> → **탁월한 효율성·품질·혁신·고객대응성** → 차별화/낮은 원가 → 가치 창출 → 우월한 수익성 → [단] 4요소·순서
- 【PPT 밖】 교수 "역시 여기서는 **자원이 중요**" — 각 자원을 기능 수준에서 어떻게 구축·정렬하는가

## 8. 탁월한 효율성 (26~34쪽) ★★★

- **효율성 = 산출물 ÷ 투입물** → [단]
- **규모의 경제(27)** = 산출량이 증가할수록 단위원가가 감소 / 원천 1 **고정비의 분산** · 원천 2 **분업과 전문화** → [단] 원천 2
- **규모의 비경제** ★★★(교수 "알아두셨으면") = **Q1**을 넘으면 **관료주의·경영 비효율** — 정보가 수많은 경영계층을 거치며 왜곡, 잘못된 의사결정 → [단] 원인 / [선] U자 곡선 해석
- **학습효과(28)** = **실행을 통한 학습** / 반복 → 노동생산성·경영효율↑ → 단위원가 곡선 **전체가 아래로** / 복잡한 작업일수록 중요 / 서비스에서도 유효 / **초기 2~3년**이 가장 중요, 생산시스템이 바뀌면 **다시 시작** → [단] 정의 / [선] 특징 O·X
- **경험곡선(28)** = **제품수명주기에 걸쳐** 나타나는 단위원가의 감소 / **누적 산출량이 2배**가 될 때마다 단위원가가 **일정 비율**로 감소 / **항공기 산업**에서 처음 관찰 / 기초 = **규모의 경제 + 학습효과** / 전략 = 수요 발생 전이라도 **효율적 규모의 설비 구축** + 파격적 가격·판촉·광고 → [단] 정의·최초 산업·기초 2
- 【PPT 밖】 구분 ★★★: 규모의 경제 = **같은 곡선 위 이동**(A→B) vs 학습효과 = **곡선 자체가 아래로** / 학습효과 = **인간**, 경험곡선 = **제조 환경** / 경험곡선 사례 = **코스맥스·한국콜마**(ODM, 누적 경험 → 비용↓ + 차별화) → [약]
- **유연생산기술(30)** = **셋업타임**↓ · 기계 **활용도**↑ · **품질관리**↑ → 표준제품 대량생산 수준의 단위원가를 유지하면서 더 다양한 제품 / **대량고객화(mass customization)** = **낮은 비용**과 **고객화를 통한 차별화**라는 **양립 불가능**해 보이는 두 목적을 **일치**시키는 능력 ★★★(교수 "개념 알아두시면") → [단] 정의 / 전통적 논리 = 단위원가와 제품 다양성은 **상충**
- **마케팅과 효율성(31)**: 명확한 경로 = 공격적 가격·판촉·광고로 **경험곡선 아래로** / 덜 명확한 경로 = **고객이탈률(churn rate)**↓ — 신규고객 획득은 **일회성 고정비** → 오래 유지할수록 평균 단위원가↓ → [선] 두 경로 구분 / 【PPT 밖】 = **리텐션**
- ★ 읽고 넘기기: 로봇 통계(한국 631대, 보잉 737 생산 2배·노동력 30%), Koren 생산방식 변천 / 【PPT 밖】 로봇 토론(32): 자동화 = 무조건 효율↑ 아님(서빙로봇·무인매장 반례) → [약] 찬반 소재
- **인적자원(33)** ★★★(교수가 유일하게 설명한 행): **자율관리팀**(**5~15명**, **직무순환**, **권한위임** → **30% 이상** 생산성↑), 성과보상은 **개인보다 팀** → [선] / ★ 나머지 행(자재관리 JIT·R&D·정보시스템·기반구조)은 읽고 넘기기
- 【PPT 밖】 **MBO → OKR(34)** ★★★(교수 "무조건 봐야"): OKR = **자율적으로 목표를 설정**하고 스스로 **이행·점검**하는 구조 / (일반 정의) MBO = 합의한 목표의 달성도로 평가 vs OKR = 도전적 목표(O) + 핵심 결과(KR), 60~70% 달성이면 성공 → [단]·[선] MBO vs OKR

## 9. 탁월한 품질 (35~38쪽) ★★★

- 품질 = **신뢰성(reliability)** + **우수성(excellence)** → **차별화와 비용절감을 동시에** → [단] 2축
- **데밍의 연쇄반응(36)**: **품질향상 → 비용감소 → 생산성향상 → 점유율·가격↑ → 수익성↑ → 일자리 창출** → [단] 순서
- **6시그마 = 100만 개당 3.4개 불량**(99.99966%) / TQM → SIX SIGMA, 1980년대 **일본**의 부상 이후 확산 → [단] 수치
- 【PPT 밖】 교수 ★★★: 품질관리의 핵심은 **검수가 아니라** TQM 관점의 **정렬(alignment)** → [선]
- **블랙벨트(37)** = 정규업무를 면제받고 **2년간** 6시그마 프로젝트 전담 → [단] / ★ 읽고 넘기기: GE CT 스캐너 사례, 신뢰성 실행 표·원칙 9 — 메시지는 **전 기능 정렬**(교수 "이 표를 굳이 가져온 이유") ★★★
- **우수성 속성(38)** 3그룹: **제품**(형태·특징·성능·내구성·신뢰성·스타일) · **서비스**(주문 용이성·납기·설치·고객 훈련·고객 컨설팅·유지보수와 수리) · **조직구성원**(역량·예의·진실성·신뢰성·대응성·커뮤니케이션) → [선] 속성→그룹 / 4단계: ① 마케팅 정보 수집 ② 속성 설계와 훈련 ③ **핵심 속성 촉진 — 한두 개만**(볼보 안전·내구성 vs 포르쉐 성능·스타일) ④ 끊임없는 향상 → [단]

## 10. 탁월한 혁신 (39~41쪽) ★ ← 교수 "넘어가도 되는데요" / 교재 범위라 이름만 [선·낮음]

- 혁신 실패 5: **불확실성 · 불완전한 상품화 · 어설픈 포지셔닝 · 수요 없는 기술 · 느린 사이클타임** / 사례: 세그웨이 = 수요 없는 기술, GM 5년 = 느린 사이클타임, 윈도우 모바일 vs 아이폰 = 포지셔닝 / 주요 R&D 프로젝트의 **10~20%만** 상업적 성공
- 교차기능팀 5속성: 챔피언 리더 · 핵심 부서에서 최소 1명씩 100% 전념 · 물리적으로 동일 장소 · 명확한 계획·목표·개발예산과 단계별 인센티브 · 자체 의사소통·갈등해소 프로세스(퀀텀)

## 11. 탁월한 고객대응성 (42~44쪽) ★★★

- 고객대응성 = 고객이 **원하는 것**을, **원하는 시간**에, **지불하고자 하는 가격**으로 → [단] 3요소
- 효율성·품질·혁신은 **모두 고객대응성을 달성하기 위한 것** → [선] O·X / 선행조건 2: ① 고객에 **집중**·요구 **파악** ② 더 좋은 충족 방법을 **끊임없이** 찾기
- 3요소: **FOCUS 고객에 집중 · CUSTOMIZATION 고객화 · RESPONSE TIME 대응시간** → [단] / 사례: **아마존** = 고객화(구매내역 기반 개인화), **캐터필러** = 대응시간(예비부품 **24시간 내** 배달 → 코마츠 저가 공세에도 충성도) → [선] / ★ 읽고 넘기기: 톰 모나한·로이 다이먼트·랜즈엔드
- 【PPT 밖】 **NPS(순추천지수)(44)** ★★★ = 고객이 타인에게 **추천자(promoter)**가 되는지 보는 지표, 교수 "고객대응성 측정에서 **가장 각광**받는 지표" / (일반 정의) 0~10점 중 9~10 추천자, 0~6 비추천자, **NPS = 추천자% − 비추천자%** → [단]
