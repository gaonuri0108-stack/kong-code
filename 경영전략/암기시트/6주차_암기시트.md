## 도입: 이 장의 질문 (4쪽) ★★★

- ① 같은 사업수준전략도 산업의 **"나이"**에 따라 달라지는가? — 파편화 → 신생·성장 → 성숙 → 쇠퇴 / ② 초기시장의 승자는 왜 대량시장에서 무너지는가? — 혁신자·조기수용자 ≠ 조기다수이용자 — **캐즘** / ③ 성숙산업에서 가격전쟁을 피하는 방법은? — **진입억제 · 가격신호 · 비가격경쟁 · 생산능력통제** / ④ 하이테크 산업은 왜 **"승자독식"**이 되는가? — **기술표준 · 네트워크효과 · 전환비용 · 선발주자** → [선] 질문↔개념 / [약] 질문 그대로
- 결론: "**어떻게 경쟁할 것인가**"를 **산업의 발전 단계와 기술 변화**에 맞춰 조정하기 → [단]
- ★ 읽고 넘기기: 도입 영상 2개 — 낫코 '주세페'(AI로 신제품 개발 1~2년 → 4~6개월), 필립모리스 '진(ZYN)'(쇠퇴산업 전략 → 5장 리더십 사례로 다시 등장)

## 1. 파편화된 산업에서의 전략 (6~13쪽) ★★★

**파편화된 산업 (7쪽)** ★★★
- **파편화된 산업(fragmented industry)** = **상당수의 소규모·중간규모 기업들**로 구성된 산업 → [단] 정의 빈칸
- 이유 3: **규모의 경제가 미미하다**(고정비가 낮아 소규모로도 손익분기점, 규모의 비경제도 가능 — 지역 유명 레스토랑) · **브랜드 충성도가 지역적이다**(지역을 잘 아는 중개인, 마사지사 개인의 기술) · **진입장벽이 낮다**(**신규 진입의 지속적 유입**이 산업을 파편화 상태로 유지, **"주인의식" 산업**) → [단] 3이유(두문자: 규·브·진)
- 【PPT 밖】 교수 "세 번째가 사실은 가장 크죠" = **진입장벽이 낮다** ★★★ / **주인의식 산업** = 소유주가 **직접 몸을 갈아 넣어** 운영하지 않으면 매출·경쟁력이 떨어지는 구조(한국 소상공인) → [선] 가장 큰 이유 / [단] 의미

**Fragmented vs Consolidated (8쪽)** ★★★

| Fragmented(4) | Consolidated(5) |
| --- | --- |
| **지역성·근접성**(음식점·카페, 미용실·세탁소, 부동산 중개) | **규모의 경제·고정비**(반도체, 완성차, 항공기, 조선 3사) |
| **현장·숙련의존**(건설 하도급·인테리어, 자동차정비, 법무·세무) | **네트워크 효과**(검색·SNS, 모바일 OS, 카카오톡, 배달앱) |
| **수요의 다양성**(패션·의류소매, 가구·공방, 꽃집·베이커리) | **규제·인허가**(통신 3사, 은행·보험, 담배·주류·카지노) |
| **규모의 경제 부재**(화물운송, 택배 대리점·퀵서비스) | **브랜드·광고**(코카콜라·펩시, 라면) / **유통장악**(대형마트, 편의점, 쿠팡·네이버, 비자·마스터) |
| 공통점: **고정비 낮음 · 수요 분절 · 진입장벽 낮음** → **입지·관계·숙련**으로 경쟁 | 공통점: **고정비 높음 · 수요 균질 · 진입장벽 높음** → **규모·브랜드·플랫폼**으로 경쟁 |

- → [선] 산업 → 유형 매칭, 공통점 빈칸
- 토론질문: 한국 외식업은 **'프랜차이즈 공화국'**인데 왜 여전히 **분산형 산업**인가? → [약]
- 【PPT 밖】 토론 답 ★★★: 교수 = **IMF 이후 중장년층의 창업** / 학생(교수 수긍) = ① **행정 절차 간단·규제 적음** ② **배달 인프라** ③ **밥을 소통 수단**으로 여기는 문화 / 교수: fragmented = **기회**가 많은 곳(consolidate하면 큰 가치), Consolidated 요인 중 **규제·인허가**도 중요(통신 3사)

**가치혁신을 통한 통합 (9~10쪽)** ★★★
- 표(10쪽): 1990년대 동네 세탁소 vs **크린토피아(1992~)** — 와이셔츠 **500원 정찰제**·**전국 균일 품질** / **접수점(대리점)과 세탁공장(지사) 분리** / **POS와 세탁물 태그**로 추적·**매뉴얼 표준화** / **개별 맞춤 최소화** — 대신 저렴한 정찰가격, 어느 지점이든 동일 서비스 / **'시간은 없고 가격에 민감한'** 가구 → [선] 표 빈칸
- 경영자들은 **"고객군에게 중요한 것"**에 대해 기존 기업과 다른 생각 / 한국 통합 사례: 하이마트, CGV, 교보/영풍문고, 스피드메이트, 메가스터디, 야놀자 → [선]
- 저렴한 가격 두 원천: **점포 표준화로 종업원 생산성↑** + **구매력에서 오는 규모의 경제** → [단] / 교훈: 파편화된 산업은 **열린 시장 공간**, 일종의 **"블루오션"** — 가치를 다르게 규정하고 규모의 경제로 더 낮은 가격에 → [단]
- 【정정】 10쪽 제목 '스테이플스'는 교재 사례 — 교수 "스테이플스가 아니고 크린토피아" / PPT '영품문고' = '영풍문고' 오타
- 【PPT 밖】 크린토피아 ★★: IMF 때 '세탁 편의점' 소자본 창업으로 확장 / 호텔 세탁(허가제) 기업 **인수로 진입장벽을 넘음** / 진짜 경쟁자 = **스타일러·SPA 브랜드**(교수)
- ★ 읽고 넘기기: 국내 세탁기업 매출 그래프(크린토피아 2024년 2796억 원)

**체인화·프랜차이즈화·수평적 합병 (11쪽)** ★★★

| 전략 | 내용 | 장점 | 단점·위험 |
| --- | --- | --- | --- |
| **체인화** | 기본방식을 동일하게 고수하는 지점을 다른 지역에 개설, **정보시스템으로 밀접하게 결합** | **빠른 전국 브랜드 구축**, 대규모 구매 교섭력과 재고통제, **수익이 전부 회사로** | **자본과 관리 부담을 본사가 전부** 짊어짐 |
| **프랜차이즈화** | 프랜차이저가 **수수료**를 받고 상호·비즈니스모델 **사용권**을 프랜차이지에 **라이선싱** | ① **프랜차이지의 자본**으로 빠른 확장 ② **독자 소유주**로서 강한 동기 ③ **지역시장 지식** | ① 체인화만큼 **엄격한 통제 불가** ② **수익 일부**가 프랜차이지에 ③ **영세한 프랜차이지의 높은 자본비용** |
| **수평적 합병** | **경쟁자들을 합병·인수**해 규모의 경제와 전국 브랜드 | 소수의 강력한 플레이어로 통합 | **과다지불**, **"레몬" 인수**, **문화충돌** |

- → [단] 장점 3·단점 3 / [선] 체인화 단점 ↔ 프랜차이즈화 단점 바꿔치기
- 【PPT 밖】 사례 짝 ★★: 체인 = **스타벅스**, **SPC**(교수 "체인과 관련해서 가장 잘한 기업"), **준오헤어**(직영 위주 → 지점별 품질관리 용이, 블랙스톤 인수 추진 / 위기 = 개별화 트렌드·정형화 비판) / 프랜차이즈 통제 불가 = **홍콩반점** / 영세 프랜차이지 = 한국의 "뇌관" / 수평적 합병 = 크린토피아 호텔 세탁 인수 → [약] 사례 → 장단점
- ★ 읽고 넘기기: 수평적 합병 위험 = 모든 M&A의 위험(교수 "이 시간에는 체인과 프랜차이즈 정도로만"), SPC 창업사(상미당 → 삼립 → 샤니의 역전)

## 2. 신생산업과 성장산업에서의 전략 (14~18쪽) ★★★

**신생산업 (15쪽)** ★★★
- 대부분의 신생산업은 **새로운 기술혁신**이 신제품 기회를 만들 때 출현 → [단]
- **초기수요가 제한되는 다섯 원인**: 초기 제품의 **낮은 품질과 성능 한계** · 신제품 사용에 대한 **고객의 생소함** · 구매를 어렵게 하는 **열악한 유통경로** · 가치를 높일 **보완제품의 부족** · 소규모 생산으로 인한 **높은 생산비용** → [단] 5원인(두문자: 품·생·유·보·비)
- **대량시장이 출현하는 세 조건**: **지속적 기술 진전**(제품 사용이 쉬워지고 가치 증대) · **보완제품의 개발** · **생산비용 절감**으로 가격 인하 → 수요 활성화 → [단] 3조건(두문자: 기·보·비)
- 【PPT 밖】 교수 ★★★: 5원인 중 "제일 큰 것" = **보완제품의 부족**, 3조건의 "핵심은 **보완재**"(애플이 블랙베리와 달리 대량시장화 = **앱스토어**) / 초기 수요가 제한될 때 = **'선교사' 역할**(강점을 알리고 직접 체험시키기 — 사우나 창업자) → [선] 가장 큰 원인 / [약]
- 【PPT 밖】 사례 ★★: 생소함 = 메타버스 / 수요 활성화 = **헨리 포드 고임금**(노동자가 잠재 소비자로)

**S자 곡선과 다섯 고객집단 (16쪽)** ★★★
- **혁신자**(불완전·고가라도 신기술을 실험하고 "**소유**"하려는 기술애호가, **위험회피 성향 낮음**) → **조기수용자**(**응용 가능성**을 인식하고 **새 용도를 개척**) → **조기다수이용자**(**실용적**, **가격 대비 이득** → **대량시장의 시작**) → **후기다수이용자**(**~50% 침투 후**, 보수적·"고령자", 유용성이 확실히 자리 잡은 뒤) → **느린수용자**(**강제되지 않는 한 거부**) → [선] 집단↔특성 / [단] 순서
- **종 모양 곡선**: 조기·후기다수이용자가 진입할 때 **최대 수요와 산업이익**이 발생 / 혁신자·조기수용자를 사로잡은 선도기업도 **다수이용자를 얻지 못하면 파산** → [선] O·X
- 【PPT 밖】 ★★★ 출처 = **로저스 『개혁의 확산』** / 교수: 다수 이용자가 **70% 이상** → 핵심은 "어떤 고객 집단부터 타깃해 어디까지 확산할지"의 **전략 설계** → [약]

**캐즘 (17쪽)** ★★★
- **캐즘(chasm)** — **제프리 무어**: "혁신자·조기수용자와 조기다수이용자의 **니즈가 너무 달라**, 초기 신생시장에서 성공한 사업수준전략과 대량시장에서 필요한 전략은 **상당히 다르다**" → [단] 정의·학자

| 차원 | 초기 신생시장(혁신자·조기수용자) | 대량시장(조기다수이용자) |
| --- | --- | --- |
| 제품 | **성능 향상**에 집중, 한계점을 기꺼이 용인 | 사용의 **편의성과 신뢰성** |
| 유통·마케팅 | **전문화된 유통경로**, **입소문** | **대량시장 유통경로**, **대중매체 광고** |
| 가격·생산 | **가격에 덜 민감** → **고비용 소량 생산** | **합리적 가격**의 고품질 → **대규모 생산** |
| 확산 | 기술적 지식으로 **스스로 판단** | **사회적 과정** — **친구·동료**가 쓰는 것을 보고 |

- → [선] 표 좌우 바꿔치기
- 【PPT 밖】 캐즘 사례 ★★★: **구글 글래스**(1,500달러, 기술 과시) vs **메타 스마트 글래스**(**레이밴** 협업, 유용성·사용성) → 캐즘 통과 = **사용성·유용성까지 고려** → [약]

**시장성장률 5요인 (18쪽)** ★★★
- **상대적 이점**(니즈를 더 잘 충족한다고 인식) · **복잡성**(사용하기 어렵거나 복잡하게 여겨지면 확산이 더딤) · **호환성**(니즈·현존 가치와 부합) · **시용가능성**(시험적으로 써볼 수 있는 정도) · **관찰가능성**(사용 결과를 다른 사람이 관찰) → [단] 5요인(두문자: 상·복·호·시·관)
- 【정정】 교수는 '시용가능성'을 "오타인 것 같다 … 사용 가능성"이라고 읽음 — 정의(시험적으로 써볼 수 있는 정도) = trialability → 시험은 **PPT 용어(시용가능성)**로
- 【PPT 밖】 ★★★ 교수 "이 이론은 좀 **알아두셨으면**" — **TAM(기술수용모델)** 핵심 2 = **Perceived Usefulness**(유용성) · **Perceived Ease of Use**(사용 용이성) → 태도 → 행동의도 → 실제 사용 → [단]
- ★ 읽고 넘기기: UTAUT·UTAUT2 도식(성과 기대·노력 기대·사회적 영향·촉진 조건 + 쾌락적 동기·가격 가치·습관)

## 3. 성숙산업에서의 전략①: 진입억제 (19~21쪽) ★★★

## 예상 문제 (셀프 테스트) — 정답은 맨 끝

### 선택형

1. 파편화된 산업의 세 가지 이유 중 교수가 "사실은 가장 크다"고 한 것은? ① 규모의 경제가 미미하다 ② 브랜드 충성도가 지역적이다 ③ 진입장벽이 낮다 ④ 수요가 균질하다
2. 다음 중 Consolidated 산업의 유형이 아닌 것은? ① 네트워크 효과 ② 규제·인허가 ③ 수요의 다양성 ④ 유통장악
3. 프랜차이즈화의 단점·위험이 아닌 것은? ① 체인화만큼 엄격한 통제 불가 ② 수익 일부가 프랜차이지에 ③ 영세한 프랜차이지의 높은 자본비용 ④ 자본과 관리 부담을 본사가 전부 짊어짐
4. 다섯 고객집단 중 "실용적, 가격 대비 이득을 따진 뒤 진입 → 대량시장의 시작"에 해당하는 집단은? ① 혁신자 ② 조기수용자 ③ 조기다수이용자 ④ 후기다수이용자
5. 캐즘 비교표에서 대량시장(조기다수이용자)의 특징은? ① 성능 향상에 집중, 한계점을 기꺼이 용인 ② 전문화된 유통경로, 입소문 ③ 가격에 덜 민감 → 고비용 소량 생산 ④ 사회적 과정 — 친구·동료가 쓰는 것을 보고 수용
6. 시장성장률을 좌우하는 다섯 요인에 해당하지 않는 것은? ① 상대적 이점 ② 관찰가능성 ③ 호환성 ④ 지각된 사용용이성(Perceived Ease of Use)
7. 성숙산업의 진입억제 전략이 아닌 것은? ① 제품증식 ② 한계가격설정 ③ 가격선도 ④ 전략적 몰입
8. 한계가격설정에서 기존 기업이 설정하는 가격은? ① 단기 이윤극대화 가격(a) ② 진입자 원가(b)보다 높은 "가격 우산" ③ 자사 원가보다는 높지만 진입자 원가 바로 아래(c) ④ 자사 원가보다 낮은 약탈적 가격
9. 올리브영이 기존 매장·기존 제품으로 외국인 관광객이라는 새 세분시장을 공략하는 것은 비가격경쟁의 어느 전략인가? ① 시장침투 ② 제품개발 ③ 시장개발 ④ 제품증식
10. 쇠퇴산업에서 경쟁의 강도가 높고 잔존 수요처와 관련된 기업의 강점이 적을 때 적합한 전략은? ① 리더십 ② 틈새 ③ 수확 ④ 철수

### 단답형

1. 파편화된 산업(fragmented industry)의 정의를 쓰시오.

3. 가치혁신으로 파편화된 시장을 통합할 때 저렴한 가격의 두 원천은?

### 약술형
